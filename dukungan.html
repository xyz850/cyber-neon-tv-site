Pusat Dukungan

Temukan panduan dasar untuk memasang dan menggunakan ION TV Player di HP Android maupun Android TV Box.

Download APK Laporkan Masalah

1. Cara memasang aplikasi

  1. Tekan tombol Download APK di atas.
  2. Tunggu sampai unduhan selesai.
  3. Buka file APK dari notifikasi unduhan atau folder Download.
  4. Jika Android meminta izin memasang aplikasi dari sumber ini, aktifkan izin hanya untuk aplikasi yang kamu gunakan untuk membuka APK, lalu lanjutkan instalasi.
  5. Setelah selesai, buka ION TV Player.

Unduh hanya dari tautan rilis resmi proyek. Android TV Box tertentu mungkin memerlukan pengelola file atau metode pemasangan yang sesuai dengan perangkatnya.

2. Video tidak bisa diputar

  • Periksa koneksi internet perangkat.
  • Pastikan alamat sumber masih aktif dan kamu memiliki izin untuk mengaksesnya.
  • Coba sumber lain yang diketahui berfungsi.
  • Sumber tertentu mungkin memerlukan akses, header, atau lisensi yang hanya dapat diberikan oleh penyedia resminya.

3. Layar kosong atau aplikasi bermasalah

  • Tutup aplikasi lalu buka kembali.
  • Mulai ulang perangkat jika masalah berlanjut.
  • Pastikan perangkat memakai versi Android yang didukung.
  • Catat langkah yang menyebabkan masalah sebelum mengirim laporan.

4. Menggunakan Android TV Box

Gunakan tombol arah dan OK pada remote untuk berpindah serta memilih kontrol. Jika suatu kontrol sulit dijangkau, coba perangkat input lain yang kompatibel, seperti mouse USB atau Bluetooth.

5. Hubungi dukungan

Gunakan halaman Issues di GitHub untuk melaporkan bug atau mengajukan saran. Sertakan model perangkat, versi Android, versi aplikasi jika diketahui, dan langkah untuk mengulangi masalah.

Jangan sertakan kata sandi, token, alamat playlist pribadi, atau informasi rahasia dalam laporan publik.
